🎤 Microphone for the hubIdle
When the hub's survey card is listening, what you say shows here too.
The first time, Chrome asks to use the microphone on this page: choose Allow and it is remembered. If you blocked it, click the 🔒 / ⓘ icon in the address bar, set Microphone to Allow, then press 🎙 TEST MIC again. A headset that is switched on and within arm's reach is enough; you do not need to hold it.
This tab only listens to the hub that opened it. It closes itself when that hub closes. Chrome Memory Saver may put it to sleep after a long idle... if it ever stops blinking, close it & click anywhere in the hub to reopen. Windows notifications from the hub keep working either way.
